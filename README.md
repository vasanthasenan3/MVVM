# 🚀 MVVM

A C# WPF practice project demonstrating the **Model-View-ViewModel (MVVM)** architectural pattern through practical examples.

## 📂 Project Structure

* **📁 Model**

  * Represents application data and business logic.

* **📁 View**

  * Contains the WPF UI using XAML.
  * Displays data and handles user interactions.

* **📁 ViewModel**

  * Connects the Model and View.
  * Manages UI-related data and commands.
  * Implements `BaseViewModel` and `INotifyPropertyChanged`.
  * Uses `RelayCommand` to implement `ICommand`.

## 🛠️ Technologies Used

* C#
* .NET
* WPF (Windows Presentation Foundation)
* XAML
* MVVM Architecture

## 📚 Concepts Practiced

* Model-View-ViewModel (MVVM)
* Separation of Concerns
* Data Binding
* `INotifyPropertyChanged`
* `ICommand`
* `RelayCommand`
* `BaseViewModel`

## 🎯 Purpose

The purpose of this repository is to understand and practise the MVVM architecture in WPF applications by separating application data, UI, and presentation logic into individual components.
